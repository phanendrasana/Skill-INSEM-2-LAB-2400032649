# Task Management Spring Boot Project

A runnable Spring Boot REST API with Spring Data JPA, an in-memory H2 database,
and a `@DataJpaTest` repository integration test.

## Requirements
- JDK 17 or later
- Maven 3.6+ (or use the Maven wrapper generated by your IDE)

## Run the repository integration test

From this project folder:

```bash
mvn test
```

The `TaskRepositoryTest` uses `@DataJpaTest`. Spring Boot configures a JPA test
slice and an embedded H2 database. The test saves a task, checks its generated
ID, retrieves it by ID, and verifies its fields.

## Run the application

```bash
mvn spring-boot:run
```

The API starts at `http://localhost:8080`.

### Create a task

```bash
curl -X POST http://localhost:8080/tasks \
  -H "Content-Type: application/json" \
  -d '{"title":"Prepare lab record","description":"Complete repository testing"}'
```

### Get a task

```bash
curl http://localhost:8080/tasks/1
```

### H2 console

Open `http://localhost:8080/h2-console` while the app is running.

- JDBC URL: `jdbc:h2:mem:taskdb`
- User Name: `sa`
- Password: leave blank

## Viva answers

1. **What specialized Spring slice context is loaded?**  
   `@DataJpaTest` loads the JPA test slice. It configures entities, Spring Data
   repositories, and the embedded database without starting the complete
   application context or unrelated web components, making tests faster.

2. **Why are test transactions rolled back automatically?**  
   Each repository test runs in a transaction that is rolled back after the
   test method. This isolates tests and prevents test data from remaining in
   the database or affecting other tests.
